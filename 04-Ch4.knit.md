## Introduction

Treatment of chickenpox (varicella) cases uses up significant economic resources in Hungary. The Hungarian authorities were interested in the past in determining whether widespread distribution of a chickenpox vaccine would be appropriate (Meszner, Molnar, Rampakakis, Yang, Kuter, & Lara, 2017). The data used for this project are 521 weekly Hungarian chickenpox case counts by county from 2005 to 2014 inclusive, with Budapest regarded as its own administrative region. This data were provided publicly by Rozemberczki, Scherer, Kiss, Sarkar, and Ferenci (2021) and downloaded from the UCI Machine Learning Repository (University of California, 2021).

The decision to make vaccines publicly available was already approved in 2018 (“Hungary to provide chickenpox vaccine”, 2018). Nevertheless, the data set may still be able to provide additional insights.

My research question is to study whether population density plays a role in the behaviour of the time series. I am interested in whether higher population density may result in a greater number of “super-spreader” events. One key factor will be seasonality in the data set, as it is thought that that colder seasons and the timing of the school year have a significant effect on chickenpox cases (Rozemberczki et al., 2021). This may have different effects in the regions of differing population density.

A natural choice in answering this research question is to fit multiplicative seasonal ARIMA models to the chickenpox case numbers, as we can study both seasonality and the case-number dependence on previous values and forecast errors. We will do so for four chosen Hungarian regions.

## Exploratory data analysis

Administratively, Hungary is split up into its counties, while the capital city, Budapest, is given a separate designation. Budapest which has, by far, the highest population density in the data set, was an obvious choice to include in my study. Of the remaining data sets, I have chosen the counties with the highest, median and lowest population densities, which are Pest, Heves and Somogy respectively (Hungarian Central Statistical Office, 2019).

On a technical note, I chose to aggregate the weekly data into monthly data. Weekly data is difficult to handle for many reasons, particularly since the seasonal period is not exactly 52 (Hyndman & Athanasopoulos, 2021).

Let us define an outlier as an observation that is either greater than 3 interquartile ranges above the 0.75 quantile, or 3 interquartile ranges below the 0.25 quantile, a fairly strict criteria detailed by Hyndman and Athanasopoulos (2021).

The only observation that qualifies as an outlier under this criteria is the case number for January 2007 in the Heves series, which has a very clear peak in Figure 1. However, if we replace this observation with the average of the cases in January of the preceding and subsequent year, this outlier case disappears, but the very next month, February 2007 exceeds the outlier threshold value. Likewise, this behaviour repeats if we adjust the February 2007 observation. This process repeats itself until we replace the April 2007 observation, but then other observations at different times are flagged. Hence, it can be regarded that these values may not be true outliers, such as a once-off super-spreader event. Therefore, no change is made to the Heves series.

## Methodology

### Initial setup

This project will use R to fit Bayesian models (R Core Team, 2021). The interface used to write in R is RStudio (RStudio Team, 2021). The Stan programming language is indirectly used (Carpenter et al., 2017). Please see Appendices 1 and 2 for R packages used and R code respectively.
The aggregation into monthly data was done computationally using the fpp3 package in R, which automatically loads some packages in the tidyverse collection of packages (Hyndman, 2021). This reduces the number of observations to 120 months’ worth of case counts, of which we will take 108 as training data and 12 as test data.
Finally, as discussed in Hyndman and Athanasopoulos (2021), fpp3 is used to determine the value for $\lambda$ in a Box-Cox transformation, in order to adjust for heteroskedasticity in the time series. Assuming the untransformed monthly series is $(x_t)$, this transformation is achieved for non-zero $\lambda$ via the formula $y_t = (x_t^\lambda - 1)/\lambda$.

Central to our methodology is the R package bayesforecast, which interfaces with the programming language Stan, to fit Bayesian time series models (Alonzo & Cruz, 2020).

### Order selection

bayesforecast used for ARIMA order selection, the algorithm for which is described below. Note that the process compares the BIC of frequentist fittings to find the preferred order.

Firstly, the following constraints are made for a multiplicative seasonal ARIMA model

$$
y_t \sim SARIMA(p,d,q)(P,D,Q)_{12}
$$

- $p + q + P + Q \leq 6$
- $d + D \leq 2$
- $0 \leq p \leq 5, 0 \leq d \leq 2, 0 \leq q \leq 5$
- $0 \leq P \leq 2, 0 \leq D \leq 2, 0 \leq Q \leq 2$

Steps for model selection, with exhaustive search and approximations off (stepwise=FALSE,approximation=FALSE), are based on the algorithm by Hyndman and Khandakar (2008). The first two steps are used to ensure stationarity.

1. Use Kwiatkowski–Phillips–Schmidt–Shin test(s) to determine $d$.
2. Use the period of an STL decomposition to determine $D$.
3. Exhaustively check the BIC of all possible models within the constraints to determine the preferred ${p,d,q,P,D,Q}$.

### Prior and posterior distributions

#### Sampling model
As previously, take $(x_t)$ as the untransformed monthly series. After the Box-Cox transformation, we have
$y_t = (x_t^\lambda - 1)/\lambda$.

We can determine from our fittings in Section 2.2 that the maximum order of coefficients for the models we need to fit for our sampling model is

$$y_t | \boldsymbol{\gamma} \sim \text{SARIMA}(1,0,2)(2,1,2)_{12}$$
where $\boldsymbol{\gamma}$ represents the parameters of the model.

Hence, we can simply determine the posterior distribution assuming this model, but all of the fitted models will have lower order coefficients than this one.

Our sampling model is equivalently expressed as described below.
$$
(1-\phi B)(1-\Phi_1 B^{12}-\Phi_2 B^{24})(1-B^{12})(y_t-\mu)
=
(1+\theta_1 B+\theta_2 B^2)(1+\Theta_1 B^{12}+\Theta_2 B^{24})\epsilon_t
$$

Therefore,

$$
\begin{aligned}
y_t ={}& \mu + \epsilon_t + \theta_1\epsilon_{t-1}
+ \theta_2\epsilon_{t-2} + \Theta_1\epsilon_{t-12}
+ \theta_1\Theta_1\epsilon_{t-13}
+ \theta_2\Theta_1\epsilon_{t-14}
+ \Theta_2\epsilon_{t-24}
+ \theta_1\Theta_2\epsilon_{t-25} \\
&+ \theta_2\Theta_2\epsilon_{t-26}
+ \phi(y_{t-1}-\mu)
+ (1+\Phi_1)(y_{t-12}-\mu)
- (\phi+\phi\Phi_1)(y_{t-13}-\mu) \\
&+ (\Phi_2-\Phi_1)(y_{t-24}-\mu)
+ (\phi\Phi_1-\phi\Phi_2)(y_{t-25}-\mu)
- \Phi_2(y_{t-36}-\mu) \\
&+ \phi\Phi_2(y_{t-37}-\mu),
\quad \epsilon_t \mid \sigma \sim N(0, sd=\sigma).
\end{aligned}
$$
(Equation 1)

Take $\epsilon_{11} = \cdots = \epsilon_{36} = 0$.

Hence, the likelihood for our sampling model is given by

$$
\begin{aligned}
y_t \mid \{&\mu, \sigma, \phi, \Phi_1, \Phi_2, \theta_1, \theta_2,
\Theta_1, \Theta_2, \epsilon_t, \epsilon_{t-1}, \epsilon_{t-2},
\epsilon_{t-13}, \epsilon_{t-14}, \epsilon_{t-24},
\epsilon_{t-25}, \epsilon_{t-26}, \\
&y_{t-1}, y_{t-12}, y_{t-13}, y_{t-24}, y_{t-25},
y_{t-36}, y_{t-37}, y_1, \ldots, y_{36}\}
\sim N(*, sd=\sigma)
\end{aligned}
$$

where * is the expression on the right-hand side of Equation 1 and $t = 37, \cdots, 108. (In ARIMA models, the sampling model is assumed to be normal.)

Define 

$$
\begin{aligned}
\widehat{y}_t ={}& \mu + E[\epsilon_t]
+ \theta_1\epsilon_{t-1} + \theta_2\epsilon_{t-2}
+ \Theta_1\epsilon_{t-12}
+ \theta_1\Theta_1\epsilon_{t-13}
+ \theta_2\Theta_1\epsilon_{t-14}
+ \Theta_2\epsilon_{t-24}
+ \theta_1\Theta_2\epsilon_{t-25} \\
&+ \theta_2\Theta_2\epsilon_{t-26}
+ \phi(y_{t-1}-\mu)
+ (1+\Phi_1)(y_{t-12}-\mu)
- (\phi+\phi\Phi_1)(y_{t-13}-\mu) \\
&+ (\Phi_2-\Phi_1)(y_{t-24}-\mu)
+ (\phi\Phi_1-\phi\Phi_2)(y_{t-25}-\mu)
- \Phi_2(y_{t-36}-\mu) \\
&+ \phi\Phi_2(y_{t-37}-\mu) \\[1em]
={}& \mu + \theta_1\epsilon_{t-1} + \theta_2\epsilon_{t-2}
+ \Theta_1\epsilon_{t-12}
+ \theta_1\Theta_1\epsilon_{t-13}
+ \theta_2\Theta_1\epsilon_{t-14}
+ \Theta_2\epsilon_{t-24}
+ \theta_1\Theta_2\epsilon_{t-25}
+ \theta_2\Theta_2\epsilon_{t-26} \\
&+ \phi(y_{t-1}-\mu)
+ (1+\Phi_1)(y_{t-12}-\mu)
- (\phi+\phi\Phi_1)(y_{t-13}-\mu) \\
&+ (\Phi_2-\Phi_1)(y_{t-24}-\mu)
+ (\phi\Phi_1-\phi\Phi_2)(y_{t-25}-\mu)
- \Phi_2(y_{t-36}-\mu) \\
&+ \phi\Phi_2(y_{t-37}-\mu).
\end{aligned}
$$
(Equation 2)

At iteration $t$ of our algorithm, we will generate $\epsilon_t$ from
$\epsilon_t \mid \sigma \sim N(0, sd = \sigma)$ iid for $t = 37, \ldots, 108$.
However, for any iteration prior iteration $n = 1, \ldots, t$ set
$\epsilon_n = y_n - \widehat{y}_n$, as defined in Equation 2.

#### Priors

We do not have any strong information or intuition on the priors, so we set priors that are considered weakly informative for the scale of typical ARIMA coefficients (Stan Development Team, 2021).

-   $\mu\ \sim\ N(mu = 0,\ sd = 10)$

-   $\sigma\ \sim\ Half\ Cauchy(mu = 0,\ sd = 5),\ \ \ \ \ \ \sigma > 0$

-   $\phi\ \sim\ N(0,\ 2)$

-   $\Phi_{j}\ \sim\ N(0,\ 2)\ iid,\ \ \ \ \ j = 1,2$

-   $\theta_{k}\ \sim\ N(0,\ 2)\ iid,\ \ \ \ \ k = 1,2$

-   $\Theta_{l}\ \sim\ N(0,\ 2)\ iid,\ \ \ \ \ \ l = 1,2$

Note that we treat all the priors as independent and while 10 parameters are listed here, all models fitted will be a subset of this model (and the true largest number of parameters fitted for any one model is 6).

#### Conditional posterior distributions

Let

-   $\mathbf{y} = \left( y_{37},\ldots,y_{108} \right),\ $

-   $\mathbf{\epsilon} = \left( \epsilon_{37},\ldots,\epsilon_{108} \right),$

-   $\mathbf{\gamma} = \left( \mu,\sigma,\phi,\Phi_{1},\Phi_{2},\theta_{1},\theta_{2},\Theta_{1},\Theta_{2} \right),$ and

-   $\lambda = \mu + \epsilon_{t} + \theta_{1}\epsilon_{t - 1} + \theta_{2}\epsilon_{t - 2} + \Theta_{1}\epsilon_{t - 12} + \theta_{1}\Theta_{1}\epsilon_{t - 13} + \theta_{2}\Theta_{1}\epsilon_{t - 14} + \Theta_{2}\epsilon_{t - 24} + \theta_{1}\Theta_{2}\epsilon_{t - 25} + \theta_{2}\Theta_{2}\epsilon_{t - 26} + \phi\left( y_{t - 1} - \mu \right) + \left( 1 + \Phi_{1} \right)\left( y_{t - 12} - \mu \right) - \left( \phi + \phi\Phi_{1} \right)\left( y_{t - 13} - \mu \right) + \left( \Phi_{2} - \Phi_{1} \right)\left( y_{t - 24} - \mu \right) + \left( \phi\Phi_{1} - \phi\Phi_{2} \right)\left( y_{t - 25} - \mu \right) - \Phi_{2}\left( y_{t - 36} - \mu \right) + \phi\Phi_{2}\left( y_{t - 37} - \mu \right).$

Since, we treat our parameters are independent, our conditional posterior distributions can be derived in the manner below, where all parameters can take any real value, except that $\sigma > 0$. Note that a minus in the subscript removes an element from a vector.

All parameters have been left in even if they are not directly relevant to the conditional distribution since we need to multiply all these distributions in our Markov chain Monte Carlo algorithm.

$${p\left( \mu \middle| \mathbf{y},\mathbf{\epsilon},\mathbf{\gamma}_{- \mu} \right) \propto \left\{ \prod_{t = 37}^{108}{p\left( y_{t} \middle| \mathbf{\gamma},\mathbf{\epsilon},\mathbf{y}_{- t} \right)} \right\}\ p(\mu)
}{\propto \left\{ \prod_{t = 37}^{108}{\exp\left\lbrack - \frac{1}{2}\left( \frac{y_{t} - \lambda}{\sigma} \right)^{2} \right\rbrack\ \ } \right\}\ {\ exp}\left\lbrack - \frac{1}{2}\left( \frac{\mu}{10} \right)^{2} \right\rbrack}$$

$$p\left( \sigma \middle| \mathbf{y},\mathbf{\epsilon},\mathbf{\gamma}_{- \sigma} \right) \propto \left\{ \prod_{t = 37}^{108}{p\left( y_{t} \middle| \mathbf{\gamma},\mathbf{\epsilon},\mathbf{y}_{- t} \right)} \right\}\ \left\{ \prod_{t = 37}^{108}{p\left( \epsilon_{t} \middle| \mathbf{\gamma},\mathbf{\epsilon}_{- t},\mathbf{y} \right)} \right\}\ \ p(\sigma)$$

$$\propto \left\{ \prod_{t = 37}^{108}{\frac{1}{\sigma}\exp\left\lbrack - \frac{1}{2}\left( \frac{y_{t} - \lambda}{\sigma} \right)^{2} \right\rbrack\ \ } \right\}\ \left\{ \prod_{t = 37}^{108}{\frac{1}{\sigma}\exp\left\lbrack - \frac{1}{2}\left( \frac{\epsilon_{t}}{\sigma} \right)^{2} \right\rbrack\ \ } \right\}\ {\frac{1}{\sigma}\left( 1 + \left( \frac{\sigma}{5} \right)^{2} \right)}^{- 1}$$

$$= \frac{1}{\sigma^{145}}\ \left\{ \prod_{t = 37}^{108}{\exp\left\lbrack - \frac{1}{2}\left( \left( \frac{y_{t} - \lambda}{\sigma} \right)^{2} + \left( \frac{\epsilon_{t}}{\sigma} \right)^{2} \right) \right\rbrack\ \ } \right\}{\ \left( 1 + \left( \frac{\sigma}{5} \right)^{2} \right)}^{- 1}$$

$$p\left( \phi \middle| \mathbf{y},\mathbf{\epsilon},\mathbf{\gamma}_{- \phi} \right) \propto \left\{ \prod_{t = 37}^{108}{{\frac{1}{\sigma}\exp}\left\lbrack - \frac{1}{2}\left( \frac{y_{t} - \lambda}{\sigma} \right)^{2} \right\rbrack\ \ } \right\}{\ exp}\left\lbrack - \frac{1}{2}\left( \frac{\phi}{2} \right)^{2} \right\rbrack$$

$$p\left( \Phi_{j} \middle| \mathbf{y},\mathbf{\epsilon},\mathbf{\gamma}_{- \Phi_{j}} \right) \propto \left\{ \prod_{t = 37}^{108}{{\frac{1}{\sigma}\exp}\left\lbrack - \frac{1}{2}\left( \frac{y_{t} - \lambda}{\sigma} \right)^{2} \right\rbrack\ \ } \right\}\ \exp\left\lbrack - \frac{1}{2}\left( \frac{\Phi_{j}}{2} \right)^{2} \right\rbrack$$

$$p\left( \theta_{k} \middle| \mathbf{y},\mathbf{\epsilon},\mathbf{\gamma}_{- \theta_{k}} \right) \propto \left\{ \prod_{t = 37}^{108}{{\frac{1}{\sigma}\exp}\left\lbrack - \frac{1}{2}\left( \frac{y_{t} - \lambda}{\sigma} \right)^{2} \right\rbrack\ \ } \right\}{\ exp}\left\lbrack - \frac{1}{2}\left( \frac{\theta_{k}}{2} \right)^{2} \right\rbrack$$

$$p\left( \Theta_{l} \middle| \mathbf{y},\mathbf{\epsilon},\mathbf{\gamma}_{- \Theta_{l}} \right) \propto \left\{ \prod_{t = 37}^{108}{{\frac{1}{\sigma}\exp}\left\lbrack - \frac{1}{2}\left( \frac{y_{t} - \lambda}{\sigma} \right)^{2} \right\rbrack\ \ } \right\}{\ exp}\left\lbrack - \frac{1}{2}\left( \frac{\Theta_{l}}{2} \right)^{2} \right\rbrack$$

$$p\left( \epsilon_{t} \middle| \mathbf{y},\mathbf{\epsilon}_{- \left\{ \geq t \right\}},\mathbf{\gamma} \right) \propto \left\{ \prod_{i = 37}^{t}{{\frac{1}{\sigma}\exp}\left\lbrack - \frac{1}{2}\left( \frac{y_{i} - \lambda}{\sigma} \right)^{2} \right\rbrack\ \ } \right\}\ \frac{1}{\sigma}\exp\left\lbrack - \frac{1}{2}\left( \frac{\epsilon_{t}}{\sigma} \right)^{2} \right\rbrack$$

$$= \frac{1}{\sigma^{t - 37 + 2}}\ \ \left\{ \prod_{i = 37}^{t}{\exp\left\lbrack - \frac{1}{2}\left( \frac{y_{i} - \lambda}{\sigma} \right)^{2} \right\rbrack\ \ } \right\}{\ exp}\left\lbrack - \frac{1}{2}\left( \frac{\epsilon_{t}}{\sigma} \right)^{2} \right\rbrack$$

Note that the density function for the Half Cauchy distribution on $\sigma$ is proportional to (double) the density of the Cauchy distribution, except that the support is now $\sigma > 0$.

### Markov chain Monte Carlo algorithm

The algorithm used to sample the conditional distributions of the variables is the one used in the Stan programming language, which is called the no-U-Turn sampler (Stan Development Team, 2021).

Note that the numbers of parameters $p$ varies depending on our four time series, but the maximum number of parameters fitted in one model is 6 and the minimum is 5. The initial parameter values are randomly generated (Stan Development Team, 2021).

The following algorithm is repeated 4 times, so that we have 4 chains.

**[Algorithm steps]{.underline}**

Repeat the following steps for each iteration from $i = 1,\ldots,2000$. The burn-in period will be half of the iterations. Thinning is not required.

Recall that, at its maximum number of parameters, $\mathbf{\gamma} = \left( \mu,\sigma,\phi,\Phi_{1},\Phi_{2},\theta_{1},\theta_{2},\Theta_{1},\Theta_{2} \right)$.

Let the superscript in brackets correspond to the iteration number.

Hence define the joint distribution of all parameters

$$p\left( \mathbf{\gamma}|\mathbf{\gamma}^{(i - 1)} \right) = p\left( \mu \middle| \mathbf{y},\mathbf{\epsilon},\mathbf{\gamma}_{- \mu}^{(i - 1)}\  \right)\ p\left( \sigma \middle| \mathbf{y},\mathbf{\epsilon},\mathbf{\gamma}_{- \sigma}^{(i - 1)} \right)\ p\left( \phi \middle| \mathbf{y},\mathbf{\epsilon},\mathbf{\gamma}_{- \phi}^{(i - 1)} \right)\ p\left( \Phi_{1} \middle| \mathbf{y},\mathbf{\epsilon},\mathbf{\gamma}_{- \Phi_{j}}^{(i - 1)} \right)
$$$p\left( \Phi_{2} \middle| \mathbf{y},\mathbf{\epsilon},\mathbf{\gamma}_{- \Phi_{j}}^{(i - 1)} \right)\ p\left( \theta_{1} \middle| \mathbf{y},\mathbf{\epsilon},\mathbf{\gamma}_{- \theta_{k}}^{(i - 1)} \right)\ p\left( \theta_{2} \middle| \mathbf{y},\mathbf{\epsilon},\mathbf{\gamma}_{- \theta_{k}}^{(i - 1)} \right)\ p\left( \Theta_{1} \middle| \mathbf{y},\mathbf{\epsilon},\mathbf{\gamma}_{- \Theta_{l}}^{(i - 1)} \right)\ p\left( \Theta_{2} \middle| \mathbf{y},\mathbf{\epsilon},\mathbf{\gamma}_{- \Theta_{l}}^{(i - 1)} \right)$ $\left\{ \prod_{i = 37}^{108}{p\left( \epsilon_{t} \middle| \mathbf{y},\mathbf{\epsilon}_{- \left\{ \geq t \right\}},\mathbf{\gamma}^{(i - 1)} \right)} \right\}$

At iteration $i$ of the sampling algorithm:

**Step 1**

If $i \leq 1000$, set $M = I_{p}$. Otherwise, set $M$ as the reciprocal of the diagonal values from the covariance matrix of $\mathbf{\gamma}^{(i = 1000)}$.

**Step 2**

Draw $\rho\ \sim\ N_{p}(0,M)$ and $\epsilon_{t}\ \sim\ N(0,sd = \sigma)$.

**Step 3: Generate proposal values**

Let $\mathbf{\gamma}^{\mathbf{*}} = \mathbf{\gamma}^{(i - 1)}$.

Solve the differential equations

$$\frac{d\mathbf{\gamma}^{\mathbf{*}}}{dt} = - \frac{d\log\left( p(\rho) \right)}{d\rho},\ \ \frac{d\rho}{dt} = \frac{d\log{p\left( \mathbf{\gamma}^{\mathbf{*}}|\mathbf{\gamma}^{(i - 1)} \right)}}{d\mathbf{\gamma}^{\mathbf{*}}},$$

to obtain $\mathbf{\gamma}^{\mathbf{*}}$.

The way to solve these differential equations is complex and beyond the scope of this project. The no-U-Turn sampler uses a unique 'leapfrog' algorithm that involves binary trees (Stan Development Team, 2021).

**Step 4: Metropolis-like step**

Let $H\left( \rho,\mathbf{\gamma} \right) = - \log{p(\rho) - \log{p\left( \mathbf{\gamma} \right)}}$

Step 4a: Compute acceptance ratio

$$r = \exp\left\{ H\left( \rho,\mathbf{\gamma}^{(i - 1)} \right) - H\left( \rho,\mathbf{\gamma}^{*} \right) \right\}\ $$

Step 4b: Set $\mathbf{\gamma}^{(i)} = \mathbf{\gamma}^{*}$ if $r > 1$ and to $\mathbf{\gamma}^{(i - 1)}$ otherwise.

**Step 5:** Predict the value of $y_{t}$, called $\widehat{y_{t}}$ (see Equation 2), using the parameter values in $\mathbf{\gamma}^{(i)}$,

**Step 6:** Set $\epsilon_{t}^{(i)} = y_{t} - \widehat{y_{t}}$.

### Posterior predictive checks

After the algorithm is complete, extract all the columns of $\mathbf{\gamma} = \left( \mu,\sigma,\phi,\Phi_{1},\Phi_{2},\theta_{1},\theta_{2},\Theta_{1},\Theta_{2} \right)$ as MCMC chains.

For our posterior predictive checks, we will use the *Arima* function from the *forecast* package to simulate seasonal ARIMA models with fixed coefficient values. Our main test statistic will be to compare the model, which used 108 observations, to compare to the full set of 120 observations by simulating 120 observations. Two other test statistics will be used -- the ACF and PACF of the 120 observations, as these describe the dependence structure of the time series.

These posterior checks will be conducted against the original data set, aggregated to monthly data, i.e. prior to the Box-Cox transformation, and with the estimated mean parameter subtracted. The algorithm for posterior predictive draws will work as follows.

For 1,000 loops:

1.  From the post burn-in set of $\mathbf{\gamma}$ values, draw a particular row from the coefficient matrix (i.e. parameters from the same iteration).

2.  Use the *Arima* function to simulate the appropriate ARIMA model with coefficients fixed to those that were drawn in step 1.

3.  Calculate the test statistics for these simulations.

4.  Calculate the proportion of times whether the test statistics exceed the statistics from the real data set.

Note that the Heves and Somogy series, exhibit some instabilities when trying to simulate observations, possibly due to the MA or seasonal MA coefficients being close to non-invertible. This is easily fixed by settings a 'while' loop to keep simulating until there are no *NA* values. It should be noted that the Pest series had one seasonal MA coefficient, but did not require this adjustment.

Let ESS be effective sample size. Note that ESS can be larger than the number of MCMC iterations due to negative autocorrelations (Stan Development Team, 2021). Here, we are comparing to 4,000 iterations since we ran 1,000 post burn-in iterations for 4 chains.

In Table 2, we can see that the simulated series tends to match the original series quite well, particularly the magnitudes of the original series and the PACF. The ACF could be a little closer to 0.5, but we are also using a model fitted to 108 observations to predict the ACF values of the true 120 observation data set, so if we had only compared to the ACF values of the first 108 observations, the test statistic would likely be close to 0.5.

We can also plot histograms of the test statistics, but a quick check indicates that there is not any interesting behaviour and we cannot compare to a single mean value because the series values, ACF and PACF all consist of more than one value.

Overall, the convergence checks indicate that the MCMC chains for the Budapest fitting have converged and the posterior predictive checks indicate that the model does a good job at replicating the behaviour of the original series.
